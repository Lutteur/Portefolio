# Portefolio

J'ai designé ce portfolio afin de me présenter, ainsi que de présenter les différentes compétences que j'ai pu développer durant mes 3 années de BUT à l'IUT du Havre.

Ce portfolio est une manière pour moi de montrer aux entreprises ce que j'ai acquis après mon Bac+3, ainsi que les différents projets académiques qui prouvent l'acquisition de ces compétences.

## Structure du projet

Tout d'abord, j'ai réalisé ce portfolio sous forme de site web. Pour cela, j'ai pu faire usage du framework **CodeIgniter 4** qui est le framework que j'ai appris à utiliser à l'IUT. J'ai créé le projet à l'aide de **Composer**.

En ce qui concerne les langages, j'ai utilisé PHP, CSS et JavaScript. Des langages où j'ai pu également progresser.
